Publicar directo en GitHub

Opcional. Con un token de GitHub, los cambios y las fotos se publican sin descargar nada. Seguí los pasos del README.

  1. Tocá "Descargar datos.js".
  2. Subí ese archivo a GitHub reemplazando el anterior.
  3. Recargá la tienda: ya aparecen los cambios.
